# ADR 0006: The chat is flat: no cards, no border lines

**Status:** Accepted (owner's design rule)

## Context

Bordered cards around assistant content looked heavy and cluttered the one place people read the most.

## Decision

Assistant answers, tool steps, approvals, verification, errors and chips are plain content with soft fills, never outlines. The message box keeps its outline.

## Consequences

A calm reading experience. The cost: separation relies on spacing and type, so spacing and contrast need care.
